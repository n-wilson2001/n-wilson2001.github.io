Zillow Housing Data

GitHub

Personal project to explore my interests within the housing and financial markets, while trying out different technologies I have not used before. The general concept is to have a Go application that is used to generate API requests using map coordinates for a given location to collect data from Zillow. The Go program then proceeds to interpret the data and calculate information relating to pricings, then stores them in a JSON struct which is saved to a JSON file. The user side of the application uses an interface made with HTML and Tailwind for a more modern design style, with a JavaScript layer to process user requests. The application is hosted on localhost port 5505, and the Go program listens and waits for requests. When it receives a request, its accesses the correlated data from the JSON file and returns it to the web application to be displayed to the user.

AWS To-Do List

GitHub

Web application using Python's Flask library that will allow users to create a list of tasks they need to complete. It can be hosted using an AWS EC2 Instance IaaS, with a backend built upon AWS's NoSQL DynamoDB for its cost-effective flexible storage. The Application was created with RESTful principles in mind, and makes use of an API Gateway with multiple HTTP endpoints to control traffic from the web application to Lambda functions that access the database. This helps extrapolate responsibility and spread it around as well as removing code that does not need to be running at all times in an EC2, converting them to a FaaS model.
